# Alarmas Forex

1. Crea un repositorio en GitHub (privado vale) y sube **todo** el contenido de esta carpeta a la rama `main`.
2. Pestaña *Actions* → "Build APK" (arranca solo al subir; también con *Run workflow*). Tarda ~8-12 min.
3. Al terminar, en la sección *Releases* del repo aparece `app-release.apk`. Descárgalo desde el Pixel e instálalo (permite "Instalar apps desconocidas" al navegador).
